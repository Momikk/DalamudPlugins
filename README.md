# Momikk Dalamud Plugins

Momikk 的 Dalamud 插件统一发布清单。这个仓库只维护统一安装入口；各插件的源码、图标和安装包由各自项目维护。

## 库链

在 Dalamud 设置的第三方插件仓库中添加：

```text
https://raw.githubusercontent.com/Momikk/DalamudPlugins/main/pluginmaster.json
```
